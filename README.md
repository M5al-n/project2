Saudi Arabia Real Estate (AQAR) - EDA

Project Overview
This project examines 3,718 properties in Riyadh, Jeddah, Dammam and Khobar through using Python, Pandas and Matplotlib.

Objective
- Comparison of properties price in different cities and districts.
- Price distribution and outlier analysis.
- Relationship between price, size, bedrooms and property age.
- Comparison between prices according to availability of swimming pool and front yard.
 Project Structure
- `01_Data_Cleaning.ipynb` – data cleaning and preparation.
- `02_EDA_Analysis.ipynb` - analysis and visualization.
- `SA_Aqar.csv` - original dataset.
- `SA_Aqar_cleaned.csv` - cleaned dataset.

Main Findings
- After data cleaning 3,715 listings left.
- Median estimated annual price is SAR 70,000.
- In Jeddah there is the highest median estimated annual price – SAR 95,000.
- There is the moderate correlation between size and price (r = 0.42).
- Pool and front yard availability were connected with higher median prices.

 How to use the project?
1. Run data cleaning notebook.
2. Save cleaned dataset.
3. Run EDA Analysis notebook.

Conclusion
Location, property size and its characteristics affect price difference. Annual prices are estimated as rental periods are not always known for sure.

Tools used: Python, Pandas, Matplotlib, Jupyter Notebook.
